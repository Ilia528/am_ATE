# 🍔 Я ПОКУШАЛ 3D: LEGENDARY v8.0

[🇬🇧 English](README.en.md)

🍔 Мемный 3D-шутер в браузере. Последний повар против восставшей еды. 12 оружий, 6 классов, боссы, питомцы, Death Cam. Голос кричит «Я ПОКУШАЛ!!!». Один HTML-файл, без установки.

## ✨ Особенности

- 🎬 Сюжетный режим с катсценами и рассказчиком
- 🎓 Интерактивное обучение (4 шага)
- 🔫 12 видов оружия с эволюцией
- ⚔️ 6 классов персонажа
- 🌳 Дерево навыков (15 узлов + 5 синергий)
- 👑 5 боссов, включая финального Пиццазавра
- 🌟 Система редкости врагов (обычный → легендарный)
- 🗺️ Мега-карта 200×200 с 5 биомами
- 🎒 Инвентарь и крафт зелий
- 🐾 4 типа питомцев с прокачкой
- 🏪 Случайный торговец
- ⏱️ Bullet Time (замедление времени)
- 🎬 Эпичный Death Cam со статистикой
- 🎪 Случайные события (зомби, метеорит, кровавая луна)
- 🎰 Гача, ежедневки, достижения, лидерборд
- 🌅 Цикл дня/ночи + динамическая погода

## 🚀 Запуск

1. Скачай `pokushal3d.html`
2. Открой в браузере (Chrome, Edge, Firefox)
3. Кликни 1 раз для захвата мыши
4. Играй!

**Ничего не нужно устанавливать.**

## 🛠️ Технологии

- **Three.js 0.160** — 3D-графика
- **Web Speech API** — мужская озвучка
- **Web Audio API** — генерация звуков
- **localStorage** — сохранения
- **Чистый JS**, без сборщиков и фреймворков
